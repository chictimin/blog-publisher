# 자료 부족 입력 (평가용 픽스처)

이 파일은 정상 초안이 아니라 **일부러 부족하게 만든 입력** 이다. 자료가 모자라거나 요청이 모호할 때
에이전트가 그럴듯한 내용으로 빈칸을 채우는지, 아니면 부족한 부분을 드러내는지 확인하려고 만들었다.

일부러 넣은 결함:

- frontmatter 없음 (title·date·slug 전부 없음)
- TODO 마커 잔존
- 깨진 위키링크
- 본문에 이미지 참조는 있는데 실제 파일이 없음
- 본론이 한 문단도 없음
